Sunset Runway is an original 2D flight game: chase view over mountains, patchwork fields and a winding river, with a HUD (altitude, speed, heading, throttle, fuel, damage), three missions in one flight — Ring Run, River Run, and a Final Approach landing on runway 09. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 in desktop Chrome. Play with keyboard and mouse: Up/Down climb and descend, Left/Right or A/D bank and turn, W/S throttle, mouse steer, click-hold boost, Space level wings, P pause, R restart, M mute.
