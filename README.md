Pacific Strike is an original 3D flight game. You fly a B-29 Superfortress across the Pacific toward Japan in 1945: first the long crossing over open ocean to the coast, then a dogfight against enemy fighters, trading machine-gun fire and tracers in the sky, and finally the bomb run itself — lining up the bomb sight over the target city and dropping the atomic bomb, which ends in a mushroom-cloud explosion with a blinding flash and a rolling shockwave. The world is real 3D terrain: ocean, a winding coastline, hills, and a city of about 150 buildings. You fly from a chase camera with a full HUD showing altitude, speed, heading, throttle, fuel, and hull integrity. It was built by an AI agent for make.fun's "Make the best flight game" bounty, worth $500 in USDC.

## Run it

```bash
cd game
python3 -m http.server 8000
```

Then open http://localhost:8000 in desktop Chrome.

## Controls

- Up / Down — climb and descend
- Left / Right or A / D — bank and turn
- W / S — throttle up and down
- Mouse — steer
- Click or F — fire the guns
- B — drop the bomb
- Space — level the wings
- P — pause
- R — restart
- M — mute
